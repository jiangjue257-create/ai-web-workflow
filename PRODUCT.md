# Product

## Register

product

## Users

This tool is for one person running local AI image and video generation on a Windows computer. The user may not be comfortable with code, terminals, or API details, so the interface should make the workflow obvious without technical vocabulary.

## Product Purpose

AI Web Workflow provides a local browser UI for saving an xAI API key, starting image or video generation, tracking task status, and previewing files saved on disk. Success means the user can open the local page, fill settings once, submit a prompt, and see clear progress or clear errors.

## Brand Personality

Calm, practical, trustworthy. The app should feel like a focused local workbench, not a marketing page or a complex professional suite.

## Anti-references

Avoid SaaS landing-page styling, oversized hero sections, decorative gradients, novelty controls, vague AI buzzwords, and interfaces that hide where settings, prompts, tasks, or generated files live.

## Design Principles

- Put the working tool on the first screen.
- Prefer plain labels and visible state over clever copy.
- Keep controls grouped by the user's workflow: settings, prompt, options, task results.
- Make failures understandable and recoverable.
- Keep visual styling quiet enough for repeated use.

## Accessibility & Inclusion

Target readable contrast, keyboard-operable controls, visible focus states, reduced-motion compatibility, and Chinese UI text that avoids unnecessary technical terms.
